# 実機確認マクロ(docs/04 の U1〜U12)

Python の結果を VBA と一致させるために、Excel で VBA を動かして確かめたいことをまとめたマクロです。

1. `UF実機確認.bas` を、UF検査判定.xlsm の**写し**に VBE からインポート(ファイルは CP932 / CRLF)
2. モジュール先頭の `DB_FOLDER` を、`品質基準.accdb`・`伝送用ファイル.accdb`・`SIKALOTNOW.accdb` のあるフォルダにする
3. マクロ `実機確認_全部` を実行 → シート「実機確認」ができる
4. そのシートを CSV で保存して送ってください

何も書き換えません(DB は読むだけ。ブックにはシートが1枚増えるだけ)。

| 番号 | 確かめること | 効く所 |
|---|---|---|
| U1 | 空欄・数にならない文字列と数の比較がエラーになるか。On Error Resume Next の中で If の条件がエラーのとき Then に入るか | 印刷前チェック・歪チェック・公差外確認(checks.py の `_num_eq`) |
| U5 | Format / Round / CLng の .5 の境界、Single の CStr | 上下限・表示桁・0.5刻み(vbx.py) |
| U12 | `IsDate("2026.06.22")` | 印刷履歴の削除 |
| S | Trim と全角空白、`Left("", -1)`、全角半角の比較 | MsgError・包装仕様の照合 |
| U3 | ADO Filter の全角半角・大文字小文字・末尾空白・空欄 | 測定機器の照合(トット)・照合キー |
| U4 | 全角の列名で半角の列が読めるか | キャスクのロット読込 |
| U9 | Access の返却順 | 「最初に一致した行」の決まり |
