## このVBAは何をしているシステムか

梱包課（日軽稲沢）の各ラインPCで、**出荷前の板（アルミ板）の寸法・形状検査を記録し、公差判定し、検査成績票を印刷して、検査データを工場の測定DBへ登録する**システムです。

- ライン: `L-1` / `LVC` / `HVC` / `ﾊﾞﾗﾝｻｰ` / `ﾄｯﾄ` / `Test` / `丸徳`（号機 A1〜A11）。1台のPCが1ラインを受け持つ（レジストリ「設備名」）。
- 入力: 検査員の社員カード（13桁）、ロットNo（7桁）、測定器（マイクロメータ・ノギス・コンベックス・デプス）からキーボード入力として届く伝送文字列 `DT…` / `#L…`、および手入力 `#〆…`。
- 判定: 厚・巾・丈（下限 ≤ 値 ≤ 上限）、対角線差・ラテラルボー・直角度（差 ≤ 公差）、歪（平坦度、定盤/ゲージ）、BH（バーコール硬度）、外観、検入高さ・枚数、梱包高さ。公差は仕掛DB（オーダー/製造公差）と品質基準DB（等級表）から。
- 出力: 検査成績票と不良要因票の印刷（既定プリンタ、EPSON LP-S180DN）、PDF/xlsx/CSV の保存（ローカル `C:\検査履歴` と工場共有）、`梱包検査ﾃﾞｰﾀ.accdb` への1行登録、アイカス（ホスト）への Aインプット送信（`hostsend.txt` → `SokuteiDataTrans.exe`）、日報・作業時間の記録、操作ログ。
- 特殊検査: キャスク（最大700枚）、全ヵ所（一般 / 5N / 三菱受託、最大70枚）、H494（10枚、幅はノギス）。

## 業務フロー（通常検査、UF1）

1. **起動**: Main のボタン → 初期設定値確認（設備名が無ければ SF3）→ UF1。レジストリの設備名でラインを自動選択し、作業中保存を読み戻す。
2. **検査員登録**: 社員カード13桁 → 名簿で氏名 → 直（1直 07:00 / 2直 15:00 / 3直 22:50、時間用テーブル）ごとに T1〜T3 へ。当日・当直の校正が未実施なら UF校正 を出す。
3. **ロット登録**: 7桁 → 直近5ロットの重複確認 → 仕掛DBから引当を取り込み（AccReflec）→ 包装仕様書No照合 → 歪公差（DistArray）→ 作業選択を促す。
4. **作業選択**: 厚板 / 薄板 / 少枚数 / 極厚 / スラブ（検番の頭文字・山数・オーダー厚でボタンの出し分け）。検査位置 S/U/C/D/E（/F）と行（厚1〜4、幅、丈、対角）のレイアウトが決まる。
5. **測定入力**: 伝送文字列の先頭（`DT`/`#L`/`#〆`）で入力対象を決め、次の空欄を自動選択 → 異常値除去 → 測定機器チェック → 判定（背景色 OK=緑 / NG=赤）→ 公差外なら UFConfi で「許容/保留」の理由。
6. **歪・ラテラルボー・直角度（R115のみ）・BH・検入高さ・外観** を入力。
7. **Min/Max** → 許容以外の公差外があれば中止。
8. **アイカスインプット**（UFAinput）: 梱包高さチェック → 電文作成 → `SokuteiDataTrans.exe` → result.txt を確認 → 日報記入。
9. **印刷・保存**: 必須チェック（定盤→ゲージ→歪AB→ラテラル→直角→外観→検入高さ/枚数→山数の順で最初の該当で停止）→ 検査員照合・梱包枚数照合 → 成績票・不良要因票を印刷 → 保存用シートへ追記 → `梱包検査ﾃﾞｰﾀ.accdb` へ登録 → 履歴 xlsx/PDF・CSV 保存 → ブック保存。
10. **新規検査**: 作業シートを初期化。

特殊モード（キャスク・全ヵ所・H494）はシートに直接入力し、シートの `Worksheet_Change` が判定（判定列に ○/×）します。詳細は G5。

## 判定・計算ロジック（結果を一致させるもの）

数値・境界は原文と行番号つきで G2 §3・G4 §4・G5 §4 に全部あります。代表だけ挙げます。

| 項目 | 規則 |
|---|---|
| 厚・巾・丈 | 下限 ≤ 値 ≤ 上限で OK（境界は合格）。上下限 = 基準 ± 公差。オーダー公差の±どちらかが 0 なら製造公差 |
| 対角線差・ラテラルボー・直角度 | 差（絶対値）≤ 公差で OK。対角・ラテラルの公差は品質基準DBの等級表（範囲が重なれば管理番号の小さい行、該当なしは 0）。直角度は 1.0 固定で R115 のみ |
| 0.5 刻み変換 | 0.1〜0.5→0.5 … 4.51〜5.0→5.0。**Single の誤差で .51・1.01 などが 0 になる** |
| 異常値 | 公差の 2 倍。対角は √(巾²+丈²) ± 6 |
| 重量・平坦度パターン | 比重 2.68・小数第3位切り捨て。35kg 以下（含む）がパターンA（両面定盤）、超えるとパターンB（ゲージ） |
| 梱包高さ | 実測 − 理論 が +最大厚×3/4 超、または −最小厚×1/3 未満で NG（差は小数第2位に四捨五入）。合紙 0.029（ストア 0.042）など |
| 校正 | 校正記録の最終行の日付・直が当日・当直と一致で済み。1000mm は 999.5〜1000.5 |
| 歪公差 | 品質基準DB の表（ソリ/中歪/耳歪 3級・4級、平坦度一覧QP追加、Q-S-QA-…）を照合関数（FindInList の `*`・`≠`・後勝ち OR など）で引く |

**結果を一致させるために再現が必要な VBA の性質**（G2 §0）: DB の値はすべて文字列（Null→""）、ADO の Filter による絞り込み、Single（単精度）の誤差、`Val`/`CStr` の有効桁（Single 7桁、Double 15桁）、`Format` は四捨五入・`Round` と Long 代入は銀行丸め、文字列と数値の比較、判定状態を**コントロールの背景色**で持っていること。

## 出力・印刷

- **検査成績票**（`印刷用_<L>`）と**不良要因票**（`不良要因印刷_<L>`）を1部ずつ既定プリンタへ。原紙をコピーしてセルに書き、検査形態（5種）で位置名・罫線を変える。続けて同じ2枚を PDF にして `C:\検査履歴` と工場共有 `【梱包】<LN>\yyyy.mm\dd日\` へ。
- 再印刷はシートに残っている内容をそのまま印刷するだけ（保存・CSV・PDF なし）。
- 印刷履歴は `印刷履歴管理`（LOT/日時/ライン）。起動時に 4 日以上前を削除（コメントは「30日」）。
- 履歴 xlsx はパスワード `Lot.yyyy.mm.dd` 付きで保存し、読み取り専用属性を付ける。
- **ラベル印刷・バーコード印刷はこのブックに無い**（LabelCls は画面部品）。

## エラー処理（VBA の実態）

- `On Error Resume Next` / `GoTo` が混在。共通の警告 `MsgError` は内容によって `End` で VBA 全体をリセットする。
- DB ファイルが無いと `End`（SQL_追加）。「空なら代替パス」のフォールバックは、テーブルが空か Filter に1件も該当しないときだけ働く。
- 印刷時、DB 登録に失敗してもシートと CSV の保存は続く（DB とシートがずれる）。
- `IsOver12Hours`（名前に反して1時間）がエラーメッセージを抑止する。

## 状態保持・長時間起動に関係する点

- `Application.OnTime` やタイマーは無い。待ちは Sleep と DoEvents。
- 判定結果・イベント抑止フラグはコントロールの色・Caption・Tag に分散している。
- 校正済みフラグは再アクティブ化まで再評価されない（画面を開いたまま直が変わるとブロックされない）。
- 品質基準の公差表・外注条件・ゲージ判定・梱包保護材はモジュール変数にキャッシュされ、Excel を閉じるまで更新されない。初回の読込に失敗すると 0 のまま。
