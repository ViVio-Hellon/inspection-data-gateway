# 測定値のつなぎ方(DT と #L)

測定器のボタンを押してから、検査画面の欄に値が入るまでの流れです。
VBA(UF1.INP_Change・FormRelat.PucketMove・Look_Blank・MachineTransfer)の動きを本ツールに移したもので、
2026-11-08〜09 に直した所も含みます。

```mermaid
flowchart LR
  A[測定器] -->|無線| B[受信機<br>U-WAVE-R / DDM-100]
  B -->|1件の文字| C[comport<br>文字に切り分け]
  C --> D[/api/kensa/recv<br>開いている画面へ/]
  D --> E[頭の2文字で種類<br>DT / #L / #〆]
  E --> F[種類ごとの行の範囲で<br>空いた欄を探す]
  F --> G[値を入れる]
  G --> H[検査員・作業選択・校正の確認]
  H --> I[判定・機器の確認<br>保存・公差外]
  I --> J[次の入力欄を黄色に]
```

## 1. 受信機から文字になるまで

| 受信機 | 測るもの | 1 件の区切り | 届く文字の例 |
|---|---|---|---|
| U-WAVE-R(マイクロメーター) | 厚 | CR(改行)で終わる 1 行 | `DT10001+0000015.003M` |
| DDM-100(コンベックス、Bluetooth) | 幅・丈・対角 | STX 〜 ETX で囲んだ 1 件 | `#L1222.8` |

- DDM-100 のパケット形式(`#L` + 長さの 1 バイト + 数字)は、長さのバイトを抜いて `#L1222.8` にします。数字だけで届いたときは、頭に `#L` を付けます(DDM-100 は長さの測定なので #L とみなします)。DDM-100 にはそのたびに ACK を返します。
- 受信機は、受け取った文字を「最後に取りに来た画面」にだけ渡します(検査・校正・Aインプット・キャスク・全ヵ所)。開いていない画面や隠れている画面には入れません。校正で測った値が、知らないうちに検査に入ることはありません。
- 検査・校正などの画面が受け取るのは、保守 → 測定機器ID で足した受信機からです。保守で「検査画面で受け取る」に印を付けたものがあれば、その受信機だけを使います。

コード: `ufkensa/kensa/comport.py`(`split_frames`・`ddm_text`)、`app/routes/kensa.py`(`/api/kensa/recv`)、`app/static/js/recv.js`

## 2. 文字の読み方

| 種類 | 見分け方 | 値 | 機器の番号 |
|---|---|---|---|
| DT | 頭の 2 文字が `DT` | 9 文字目から 11 文字(`0000015.003` → 15.003) | 3 文字目から 5 文字(`10001`) |
| #L | 頭の 2 文字が `#L` | 3 文字目から後ろ全部(`1222.8`) | 持たない |
| #〆 | 頭の 2 文字が `#〆` | 3 文字目から後ろ全部 | 持たない |

- 頭の 2 文字は、全角を半角に、小文字を大文字に直してから見ます。3 文字未満の文字や、頭が DT・#L・#〆 のどれでもない文字は「ﾊﾟｹｯﾄ無し」で、値を入れません。
- DT の機器の番号(例 `10001`)は、マスタ「測定機器ID」の **出力テキスト** と照らし合わせます(4 章)。

コード: `input_router.maker`・`input_router.conv`、`instruments.machin_text`

## 3. どの欄に入るか(DT は厚、#L は幅・丈・対角)

### 3.1 行の範囲

種類ごとに、探す行の範囲が決まっています。行の意味は `model.py` の `RowLayout` で決めています。

| 種類 | ふつう(厚板・薄板・少枚数・スラブ) | 極厚(耳付き) |
|---|---|---|
| DT | 厚の行。「厚2ヵ所」ボタンなら 1〜4 行(4 回検査)、「厚4ヵ所」なら 1〜2 行 | 同じ |
| #L | 5〜10 行(幅 5〜6・丈 7〜8・対角 9〜10) | 5〜14 行(幅 1〜6 = 5〜10・丈 1〜4 = 11〜14、対角なし) |
| #〆 | 1〜10 行 | 1〜14 行 |

### 3.2 位置の順番

範囲の中を、位置 S → U → C → D → E(→ F)の順に見て、**最初に空いている欄**に入れます。
作業によって飛ばす位置があります。

| 作業 | DT(厚) | #L(幅・丈・対角) |
|---|---|---|
| 厚板 | S → U → C → D → E | S → C → E(U・D は厚だけの位置) |
| スラブ | S(1-上)→ C(1-下) | S → U(5〜8 行)→ C → D(5〜8 行) |
| 薄板 | 検番と山数で決まる位置(U / C / D / E) | 同じ |
| 極厚 | S → U → C → D → E | S → U → C → D → E |
| 少枚数 | 厚板・スラブ以外と同じ順(S → U → C → D → E)。次の入力欄(黄色)は検査回数で決まる | 同じ |

- 範囲の中に空いた欄が無ければ、「DT検査済」「#L検査済」と知らせて、入力先を空にします。そのあとに届いた値は、次の入力先を決め直してから受けます(2026-11-08 に直した所。VBA はフォームの余白を押すまで値を捨てていました)。
- スラブで厚を 1-上 → 1-下 の順に入れるのは、2026-11-08 に直した所です(B90)。VBA は 1-上の厚の次の DT を、幅の欄(U5〜U8)へ入れていました。
- スラブの「#L検査済」は、画面に出ている欄だけで見ます(B91)。

コード: `input_router.pucket_move`・`input_router.all_check`

### 3.3 DT と #L が混ざって届いたとき

DT と #L は行の範囲が分かれているので、どちらから測っても、それぞれの範囲の空いた欄に入ります。
厚を全部測ってから幅・丈を測っても、1 枚ずつ厚と幅・丈を交互に測っても、入る欄は同じです。
黄色の欄(次の入力欄)は目安で、届いた種類の範囲が優先されます。

## 4. 値を入れたあと

値を入れたら、次の順に確かめます。止まったときは値を消し、理由を出します。

1. 検査員が登録されているか → 無ければ「検査員登録をして下さい」
2. 作業選択がされているか → 無ければ「作業選択してください」
3. 校正が済んでいるか → まだなら校正の画面を開く(権限で飛ばせる端末を除く)
4. 判定(公差の内か外か)・異常値の確認・機器の確認
5. 作業保存へ書く・公差外の確認

### 機器の確認(DT だけ)

- 届いた DT の機器の番号(出力テキスト)と、マスタ「測定機器ID」から引いた **このライン・この厚(と用途)に合う機器** の出力テキストを比べます。違えば「測定するﾏｲｸﾛを正しく選定して下さい ○○を使用の事」で止めます。
- 合う機器は、ライン(列「ライン」)・厚の範囲(「厚下」〜「厚上」)・用途の条件で引きます。
- #L・#〆 は機器の番号を持たないので、機器は前の DT のまま、帳票のコンベックス欄はラインで決まります(HVC は C11 など)。

コード: `input_router.inp_change`、`instruments.micro_juge`・`instruments.db_return_micro`・`instruments.machine_transfer`

## 5. 次の入力欄(黄色)

値を入れたあと、同じ順番(S → U → C → D → E)で次の空いた欄を探し、黄色と赤枠にします。
薄板は検番と山数、少枚数は検査回数、極厚は 1〜14 行で探します。

コード: `input_router.next_blank`・`look_blank`・`look_s_blank`・`smallnumber_blank`

## 6. 入らないときに見る所

| 様子 | 見る所 |
|---|---|
| 何も届かない | 保守 → 測定機器ID で受信機を足したか。保守で受信中なら止める(同じ受信機は 1 か所でしか開けない) |
| 届くが「ﾊﾟｹｯﾄ無し」 | 頭が DT / #L ではない。保守 → 測定機器ID の受信記録で、届いた文字を見る |
| 「〜検査済」と出て入らない | その種類の範囲が全部埋まっている。作業選択(厚2ヵ所 / 厚4ヵ所)を見る |
| 「ﾏｲｸﾛを正しく選定」で止まる | 測定機器ID の、このラインの出力テキスト・厚下・厚上・用途 |
| 「検査員登録」「作業選択」で止まる | 登録と作業選択 |

保守 → 測定機器ID の「伝送テスト」では、届いた文字が 1〜5 のどこで止まるかを、実際の値で確かめられます。
