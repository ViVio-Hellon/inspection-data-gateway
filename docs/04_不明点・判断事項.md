### 資料について

- **梱包検査ﾃﾞｰﾀ.accdb は後日提出**。SQLite に切り替えるので Access のまま書くことはありませんが、
  VBA は列名ではなく**列の位置**で書いているため、同じ列構成の SQLite の表を作るのと、過去の検査データを移すのに列名・列数が必要です。
  届くまでは、VBA の書き方（1列目 = ライン名、2列目以降 = `保存用` シートの A〜DJ 列、耳付は `耳用` の A〜DD 列）から表を定義して進め、届いたら突き合わせます。
  また、この DB をほかのシステム（品証の集計など）が読んでいる場合は、そちらも SQLite に合わせる必要があります（W13）。
- **印刷物の見本はブック内の原紙**（印刷用原紙・不良要因印刷原紙・各特殊検査の原紙）を使う。原紙の様式と VBA の書き込み処理から帳票を再現する。
