# 06 VBA と意図して変えたところ

業務上の結果(判定・計算・出力項目)は VBA と同じにする方針です。そのうえで、判断事項(docs/04)で決めたことや
Web にしたことで変わる所をここに残します。**ここに無い違いは不具合**として扱ってください。
VBA の既存不具合をどう扱うか(再現 / 直す)は `config/quirks.json` と設定画面「不具合の扱い」にあります。

## Web にしたことで変わる所

| VBA | Web 版 | 理由 |
|---|---|---|
| レジストリの「設備名」「モード」 | 設定画面「この端末」(`user_settings`) | レジストリに依存しない |
| パスはコードに直書き | 設定画面「使用パス」で見て直せる | ご依頼 |
| モード(オンライン/オフライン)ごとにパスの組を持つ。仕掛は MainPath と NextPath の2項目 | 仕掛台帳だけ第1パス(= MainPath)/ 第2パス(= NextPath)。モードは仕掛台帳にだけ効く: オンラインは第1 → 第1に無いファイル・ロットだけ第2(VBA はファイルがあればロットが無くても控えを見ない所がある)、オフラインは第2だけ。ほかの項目はパス1つでモードによらない(VBA のオフラインの値は使わない)。第2はファイル名を変えられる。前の保存は、パス1つの項目はいまのモードで使っていた値、仕掛の第1は旧オンラインの MainPath、第2は旧オンラインの NextPath に読み替える | D26(python-web-tools と同じ考え方) |
| 仕掛 DB を共有の上で直接開く | 手元へ写してから写しを読む(変わったときだけ写し直す)。写せないファイルは読まない(オンラインは第2へ、オフラインは「…がありません」) | D26 改(python-web-tools と同じ) |
| 上流の作り直し中(毎時 59:46〜00:45・PLEASE WAIT.txt)は控え(NextPath)を読む(TimeDesignation / FileDesignation) | **外した**(時刻も PLEASE WAIT.txt も見ない。時間チェックのログも書かない)。それに関わる B23 は効かなくなり、B49 は再現と直すで差が出なくなった | ご指示(2026-11-03、D26 改) |
| 判定状態をコントロールの背景色で持つ | 状態モデル(`grid.KensaState`)に同じ色の値で持つ。結果は同じ | 画面とロジックを分ける |
| MsgBox の Yes/No でその場で分岐 | 画面に聞いて、答えを持って同じ操作を呼び直す(`flow.Question`) | Web では処理の途中で聞けない |
| 音声(`C:\VBAWAV`)を VBA が鳴らす | ブラウザが鳴らす(使用パス「音声」) | 同上 |
| ラベルのフォント・位置・フォームの大きさ | 画面の作り(CSS)に任せる | 見た目は作り直す(D6) |
| Access の DB パスワード `nlm` | 取り込みのときだけ使う(SQLite には無い) | D4 |
| Aインプットの Reset はすぐ実行 | 「Reset しますか」を1回聞いてから実行 | 押し間違いで入力が消えるのを防ぐ。結果は同じ |
| Aインプットの検査法は UF1 の Inspection1〜4 で選ぶ | Aインプット画面で L1/L2/M6/M2 を選ぶ(この端末で覚える) | 画面を分けたため |
| Aインプットで受け付けない伝送は黙って消す | 消したうえで理由を出す(機器番号の違いなど) | 結果は同じ |
| 品証検証シートが無いと校正画面は End | VBA のブックと同じ枠(6〜98 行目、d日 × 1直/2直/3直)を作って続ける | 新しい端末でも止まらない |
| 校正記録シートは 校正() が開く前に作る | 校正画面を開くときに作る | 作らずに測ると最初の1回が記録されないため |
| 校正記録の時刻(C 列)は Excel の時刻 | 新しい行は "h時mm分ss秒" の文字。画面では同じ形で出す | 取り込んだ行と新しい行で型が違う(表示は同じ) |
| 名簿・日報(UFNameList)の日報修正は、梱包枚数が合わないときの「編集起動」からしか入れない | メニューの「名簿・日報」からいつでも開ける | 画面を分けたため。修正の中身は同じ |
| 全ヵ所・H494 で Enter を押すと Excel が1行下へ移る | Change が選択を動かさない列(ラテラル・歪・外観)では1行下へ移す(`ENTER_MOVES_DOWN`) | Excel の既定の動きをまねる |
| 全ヵ所を開くとき、最新の直の検査員欄が空だと実行時エラー9 | 検査員名をそのままにして開く | D10(止めずに続ける) |
| 全ヵ所・キャスクの保存は xlsx(パスワード・読み取り専用つき) | シートごとの CSV と HTML、Windows で Edge があれば PDF。パスワード・読み取り専用は付けない | D7 |

## 移植で外したもの(呼び出し元が無い・到達しない・画面だけの処理)

各担当の報告から。根拠は `docs/analysis/` と各モジュールの docstring にあります。

- Judg: Judg_ImageSize(画面の配置だけ)、Test_Tolerance、NflatRewrite(呼び出し元なし)
- OutTolerance: フォームの位置・色付けだけの処理、ConductivLoad の原紙コピー
- AccHIki: Lotflag・AccUpdate 系・Order_Update・Conv(呼び出し元なし)、Arrbox の L60 以降(到達しない)、Micro_Juge_旧
- FormRelat/UF1: ピクセル位置・フォームの大きさ・画像・フォーカス色だけの処理、Load_OP・CBdateCheck・EraseCount_F(呼び出し元なし)
- Input/Worker/Proofreading: ウィンドウとラベルの配置、A保存・Array2D・Daily_Report4_Execution(呼び出し元なし)、コメントアウトされた旧 Height_Check、UFAinput の試験用ボタン、日報＆資材計算.xlsm のマクロを呼ぶボタン、UFNameList の VBA 停止
- QP_DB/Quality_DB: 旧 Quality(D9)、BoColor(画面の色だけ)、Reload 系(キャッシュの読み直しで代わる)

## 試験データについて

受領した Access から試験データを作るとき、変換の道具(mdbtools)が**長さ0の文字列を Null と同じに書き出していた**。
必須(NOT NULL)の文字列の列は Access では Null になり得ないので、"" に戻した(VBA が読む値と同じ)。

## 2026-11-06 追加
- 仕掛台帳のファイル名は **第1パス・第2パスそれぞれ** 設定できる(設定 → 使用パス → 仕掛台帳「第1パスで読む名前 / 第2パスで読む名前」。空なら SIKALOT.sqlite3 など既定の名前)。
- 包装仕様書のフォルダが無いとき、VBA は実行時エラー 76 でロット登録が止まるが、こちらは注意を出して続ける(画像を出さないだけ。B84 を「直す」にしているとき)。
- 仮ロットの LotNo は英数字 7 文字(本物の形 N8281C0 も可)。
- 2026.11.06 VBA の直し【UFKen_05】OutTolerance.SmallNumberCount(157〜203 行目)に合わせた: 少枚数のラテラルの要否は JudgeLotAllocations(引当混在対策: 1 件でも要なら要)で決め、検査不要かどうか(Right(Additional, 4))は判定の後で取り直す(wiring.small_number_count → checks.small_number_count の need_lateral)。
